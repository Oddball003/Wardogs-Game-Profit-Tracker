## What's new in v1.5.1

### New
- **Pick your web browser**: **Advanced › Web browser** chooses which browser the tracker uses (Edge by default; Chrome, Brave, Vivaldi or Opera if installed). Each browser keeps its own Steam sign-in.
- **OBS sources sized for you**: with **Size OBS sources to fit** on, your overlays' Browser sources in OBS can be:
  - **Fit the overlay**: exactly the size of what they show, so there's no big empty box around them.
  - **Largest**: as big as they can ever get (amounts up to -$999,999, every leaderboard row, team badges and a longest name you set), so the source never changes size mid-game.
  - **Manual**: a width and height you type.
- **Grows**: pick which way the overlays grow (left, both ways or right; down or up). The tracker keeps that corner in place in OBS.
- **🔑 Log in to OBS**: a small window for the host, port and password, saved together and connected straight away. The saved password stays hidden until you press **👁 Show**. Log in, Test and Connect are now on the Leaderboard and Money HUD tabs of the Output editor too.
- A short warning in the Output editor when OBS isn't connected or can't be reached.

### Fixed
- OBS sources are sized again when OBS restarts or connects late.
